# AIXelerate Challenge / Brand refresh

## Direction

Match the user-supplied AIX brand board (21 September 2026): energetic,
approachable, student-led. Keep the existing page structure, event photography,
copy, application flows, and motion. The sprint and student community lead.

## Visual system

- Orange `#ff5630`, blue `#6196d6`, pale cream `#fffcd9`, and white.
- Cream and white reading surfaces, orange display accents, blue signature panels.
  Keep inner-page headlines orange on cream; reserve gradients for the hero and CTA.
- Dark blue ink and darker orange links keep small text readable on light surfaces.
- Soft orange, peach, and pink CSS gradients echo the supplied brand artwork.
- Public Stunt is the requested display face. No font file was supplied or found
  locally; Archivo Black is the bundled fallback. Poppins supplies body text and
  semibold controls. Relax display tracking and line height for the new type.
- Rounded panels and gentle shadows replace graphite and wireframe treatments.
- Natural-color event photos; retain light captions on dark photographic scrims.
- Solid concentric-shell snail and angular AIX monogram are SVG interpretations
  of the supplied brand marks, inheriting color across orange, cream, and blue.

## Reference application and scope

Use the honorably-website principle of a coherent repeated visual language:
the supplied brand board determines the palette, marks, typography, and surfaces.
Retain the existing hero collage, section sequence, galleries, and responsive
behavior. No external UI component, new effect, or runtime dependency is needed.

Existing scrolling, hover, and reveal interactions retain their current purpose
and triggers; mobile and reduced-motion presentations remain available. Inspect
desktop and narrow mobile pages after changing type metrics and contrast.
